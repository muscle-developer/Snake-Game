Snake Clash를 모작으로한 뱀 게임입니다.

게임성보단 설계와 최적화등을 공부하기 위해 집중적으로 생각하고 만들었습니다. 

- 혼자서 게임의 처음부터 끝까지 단계별로 진행해 볼 수 있었습니다.
- 조이스틱을 활용하여 오브젝트 이동 및 이벤트 처리를 사용해볼 수 있었습니다.
- 뱀의 움직임을 자연스럽게(곡선 이동) 변환하는 법을 사용했습니다.
- 플레이어의 상태에 따라 카메라 이동 및 전환효과 등을 사용해볼 수 있었습니다.
- 맵의 크기를 고려하는 Box Collider, Scale을 통한 아이템 생성을 구현할 수 있었습니다.
- 오브젝트 풀링을 통해 아이템 및 먹이등을 최적화 하여 생성 및 관리 할 수 있었습니다.
- NavMeshAgent를 활용하여 적을 AI로 이동할 수 있게 되었습니다.
- PlayerPrefs를 통해 닉네임을 생성하고 저장하여 사용할 수 있었습니다.
- Canvs 중복을 줄여 최적화에대한 공부를 할 수 있었습니다.
- 비동기 씬 전환을 사용함으로 써 비동기 씬 전환이점에 대해 공부할 수 있었습니다.
- StatePattern을 통해 게임상태를 관리할 수 있었습니다.
